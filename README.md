One letter, X, for a day best summed up by the word behind it: exhausted. Vivid, funny and true — and a sharper initial for that word than the obvious E, since X is both the first sound of ex- and the shape of a day crossed out.

## Run it

```sh
python3 main.py
```

It writes exactly one character, `X`, to `/output/entry.txt` — no word, no gloss, no punctuation, no trailing newline.
